## 3. 최적화 작업 내용

### 3.1 ani_room_allot 모드 최적화

#### 개선 방법
1. **배치 조회 방식 도입**
   - study_2 결과의 모든 NO를 먼저 수집
   - study_1 데이터를 IN 절로 한 번에 조회
   - test_substance_tb 데이터도 sample_name별로 배치 조회

2. **데이터 캐싱**
   - 조회한 데이터를 배열에 저장하여 재사용
   - 동일한 데이터에 대한 반복 쿼리 제거

#### 최적화 후 코드
```php
// study_2 결과를 먼저 배열에 저장하고, 필요한 NO와 sample_name을 수집
$study_2_data = array();
$no_list = array();
$sample_name_list = array();

mysqli_data_seek($result, 0);
while ($data = mysqli_fetch_array($result)) {
    $study_2_data[] = $data;
    $no_list[] = mysqli_real_escape_string($db_conn2, $data['NO']);
}

// study_1 데이터를 한 번에 조회
if (!empty($no_list)) {
    $no_list_str = "'" . implode("','", $no_list) . "'";
    $sql_study1_batch = "SELECT * FROM study_1 WHERE NO IN ($no_list_str)";
    $result_study1_batch = mysqli_query($db_conn2, $sql_study1_batch);
    while ($row = mysqli_fetch_array($result_study1_batch)) {
        $study_1_cache[$row['NO']] = $row;
        $sample_name_list[] = mysqli_real_escape_string($db_conn2, $row['sample_name']);
    }
}

// test_substance_tb 데이터를 한 번에 조회
if (!empty($sample_name_list)) {
    $sample_name_list = array_unique($sample_name_list);
    $sample_name_list_str = "'" . implode("','", $sample_name_list) . "'";
    $sql_substance_batch = "SELECT substance_name, st_view FROM test_substance_tb WHERE substance_name IN ($sample_name_list_str)";
    $result_substance_batch = mysqli_query($db_conn2, $sql_substance_batch);
    while ($row = mysqli_fetch_array($result_substance_batch)) {
        $substance_cache[$row['substance_name']] = $row['st_view'];
    }
}

// 캐시에서 데이터 사용
foreach ($study_2_data as $data) {
    $data_ex = isset($study_1_cache[$data['NO']]) ? $study_1_cache[$data['NO']] : null;
    $st_view = isset($substance_cache[$data_ex['sample_name']]) ? $substance_cache[$data_ex['sample_name']] : '';
    // ... 데이터 처리
}
```

#### 쿼리 실행 횟수
- study_2 조회: 1회
- study_1 배치 조회: 1회
- test_substance_tb 배치 조회: 1회

**예시**: study_2 결과 50개, 각 케이지 평균 100개
- 총 쿼리 수: **3개** (5,051개 → 3개)

## 부록: 기술 용어 설명

### N+1 쿼리 문제
- 하나의 쿼리로 N개의 결과를 가져온 후, 각 결과마다 추가 쿼리를 N번 실행하는 문제
- 예: 100개 행을 가져온 후 각 행마다 1개씩 쿼리 실행 → 총 101개 쿼리

### 배치 조회 (Batch Query)
- 여러 개의 단일 쿼리 대신 IN 절을 사용하여 한 번에 여러 데이터를 조회하는 방식
- 예: `SELECT * FROM table WHERE id IN (1, 2, 3, ...)`

### 데이터 캐싱
- 한 번 조회한 데이터를 메모리에 저장하여 재사용하는 기법
- 반복 쿼리 방지 및 성능 향상
